# GIF Studio · 动图工坊

一个使用原生 HTML、CSS 和 JavaScript 开发的浏览器 GIF 编辑器。图片、视频解码和 GIF 编码均在用户设备上完成，无需素材上传服务。

## 功能

- JPG、PNG、WebP 多图转 GIF，拖动排序及单张停留时间。
- 浏览器可解码视频转 GIF，支持截取片段、速度和帧率调整。
- 自定义画布尺寸与比例，完整显示、裁剪铺满、背景、缩放、位置、旋转和翻转。
- 单次、无限循环、自定义播放次数，以及正序、倒序、往返播放。
- GIF 画质设置、目标体积缩小建议、实际文件预览和下载。
- PC、平板与手机响应式布局。

## 本地运行

项目无需 npm 安装或构建。安装 Python 3 后，在项目目录执行：

```sh
python -m http.server 8000 --directory dist
```

访问 `http://localhost:8000`。请通过 HTTP 服务访问，不要直接双击 HTML 文件；JavaScript 模块和 Web Worker 需要正常的网页来源。

## 目录

```text
dist/
  index.html   页面结构与文案
  style.css    响应式样式
  app.js       编辑、预览与导出逻辑
  encoder.js   GIF89a 编码、调色板量化与 LZW 压缩
  worker.js    后台 GIF 编码任务
  favicon.png  AI 生成的浏览器图标
```

部署静态网站时，将 `dist` 目录作为网站根目录。源码存放到 GitHub 本身不会自动启用 GitHub Pages，也不会自动同步当前线上网站。

## 使用限制

- 视频格式取决于浏览器的解码支持，推荐常见 H.264 MP4。
- GIF 不包含音频，仅支持全透明而非半透明。
- 大尺寸、长视频和高帧率会增加处理时间及内存占用。
- 目标体积优化会先请求用户确认缩小尺寸，不能保证所有素材均达到指定大小。
- 不同查看器可能对播放次数有不同处理。
